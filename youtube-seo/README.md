# 돈이말해 YouTube SEO / Content Engine

`fire-your-seo-agency`의 검색 의도·1차 소스·측정 원칙을 YouTube 제작 흐름에 맞게 재설계한 작업 폴더입니다.

## 한 줄 사용법

다음처럼 요청하면 됩니다.

- `오늘 돈이말해 주제 뽑아줘`
- `이 뉴스로 돈이말해 풀세트 만들어줘`
- `이 주제로 제목/대본/설명/태그/썸네일까지`
- `이 영상 업로드 후 성과 분석해줘`

## 기본 산출물

1. 주제 후보 및 검색 의도
2. 핵심 사실·숫자·기준일·출처
3. 메인 키워드 / 보조 키워드 / 검색 질문
4. 제목 후보
5. 최종 추천 제목
6. 완성 대본
7. YouTube 설명란
8. 태그
9. 해시태그
10. 썸네일 문구·구도
11. 필요 시 20개 이미지 장면 프롬프트
12. 업로드 후 측정 항목

## 채널 기본값

- 채널명: 돈이말해
- 언어: 한국어
- 톤: 차분하고 명확한 존댓말
- 중심 분야: 경제, 금융, 증시, 금리, 환율, 기업, 가계경제
- 목표: 클릭을 만들되 과장하지 않고, 시청자가 끝까지 이해하게 만들기
- 핵심 시각 캐릭터: Moneybag
- Moneybag 기본: 베이지색 돈주머니 머리/몸, 묶인 윗부분, 큰 검은 둥근 눈, 분홍 볼, 작은 미소, 네이비 정장, 흰 셔츠, 주황 넥타이, 흰 장갑, 검은 구두, 치비 비율, 굵은 윤곽선, 밝은 2D 셀셰이딩
- 일반 장면 이미지 프롬프트 기본: 16:9, 이미지 내부 글자·숫자·로고 없음

## 파일

- `SKILL.md`: 전체 운영 절차
- `references/topic-research.md`: 주제 발굴
- `references/fact-check.md`: 자료조사·팩트체크
- `references/script.md`: 대본 구조
- `references/metadata.md`: 제목·설명·태그·해시태그
- `references/thumbnail.md`: 썸네일과 Moneybag 규칙
- `references/measure.md`: 업로드 후 분석
- `templates/full-output.md`: 한 번에 출력할 때의 형식

## 원칙

YouTube 검색 최적화는 태그 채우기가 아닙니다. 검색 의도와 영상의 실제 내용이 맞아야 하고, 제목·썸네일이 정확한 기대를 만든 뒤 초반 대본이 그 기대를 바로 충족해야 합니다. 최종 판단은 업로드 후 노출, 클릭률, 시청 유지율, 검색어, 시청시간으로 합니다.
